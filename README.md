# Task-Manager-API

## Setup Instructions

1. Clone the repository: git clone https://github.com/Krutarth-Aperions/Task-Manager-API.git
2. Create virtual environment & activate it
3. Install packages - pip install -r requirements.txt
4. Create .env file in the root directory of your project.
5. Add Variables - (SECRET_KEY, DEBUG)
6. Apply database migrations - python manage.py migrate
7. For run - python manage.py runserver
